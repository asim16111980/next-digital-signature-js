# مشروع التوقيع الرقمي - Next.js (JavaScript)

مشروع تعليمي يوفّر واجهة ويب بسيطة لتوليد مفاتيح RSA، توقيع نصوص/ملفات، والتحقق من التوقيع.

## خطوات سريعة
1. تثبيت الحزم: `npm install`
2. تشغيل في وضع التطوير: `npm run dev`
3. افتح المتصفح على `http://localhost:3000`
4. لتشغيل اختبار تلقائي صغير (توليد مفاتيح، توقيع، تحقق): `npm run test`

## ملاحظة أمنية
- هذا مشروع تعليمي. في بيئة الإنتاج لا تحفظ المفتاح الخاص كنص واضح على القرص؛ استخدم HSM أو تشفير للمفاتيح.
